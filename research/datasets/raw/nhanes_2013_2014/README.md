# NHANES 2013--2014 grip-strength reference

Downloaded from CDC/NCHS on demand by `scripts/research/fetch_priority_datasets.py`.

- Join components using `SEQN` **only within this survey cycle**.
- Inspect grip test status (`MGDEXSTS`) and effort fields before analysis.
- Grip strength is a measured reference, not a proxy for a user's 1RM or a
  clinical fitness clearance. Use documented examination weights and analytic
  guidance for population estimates.
