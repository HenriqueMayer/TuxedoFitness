# NHANES 2017--2018 core

Downloaded from CDC/NCHS on demand by `scripts/research/fetch_priority_datasets.py`.

- Join components using `SEQN` **only within this survey cycle**.
- For estimates that include examination data, use the documented NHANES
  examination weights (normally `WTMEC2YR`) and the component-specific analytic
  guidance.
- Read each source codebook before selecting variables or treating a missing
  value as a value.
