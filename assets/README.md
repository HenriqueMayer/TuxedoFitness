# Assets

`css/tailwind.css` is the frontend CSS source. The original Fitness emblem is
`icons/AthleticTuxedoCatEmblemWithBackground.png`; its unchanged full-resolution
web copy and compact navigation derivative live in `static/brand/`.

Compiled CSS, local fonts and HTMX are versioned so runtime installation does
not require Node. `preview/` includes independent copies for offline viewing.
